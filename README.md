# 🔐 HashForge

HashForge is a Flask-based web application for generating, verifying, comparing, and analyzing cryptographic hashes. It provides an intuitive interface for working with multiple hashing algorithms while supporting file hashing, history tracking, and report generation.

## ✨ Features

- Generate cryptographic hashes
- Verify hash integrity
- Compare two hashes
- File hash generation
- Multiple hashing algorithms
- History tracking
- Export reports
- Responsive and user-friendly interface

## 🛠️ Tech Stack

- Python
- Flask
- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/HashForge.git
   ```

2. Navigate to the project directory
   ```bash
   cd HashForge
   ```

3. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```

4. Run the application
   ```bash
   python app.py
   ```

5. Open your browser and visit:
   ```
   http://127.0.0.1:5000
   ```
